# Deuda técnica

## PoweredBy: isotipo de marca (opción B)

- **Archivo:** [`src/components/ui/PoweredBy.tsx`](../src/components/ui/PoweredBy.tsx)
- **Motivo:** Hoy se usa el icono `ExternalLink` de `lucide-react` como señal semántica de enlace externo. Cuando exista el isotipo oficial de “Escala tu negocio con IA”, sustituir por un `<img>` (o SVG inline) del asset, con `alt` descriptivo y tamaño acorde (`h-4 w-4` o el que defina la guía de marca).
